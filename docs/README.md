# OpenFoot Manager Documentation

This directory contains technical and gameplay documentation for the web version of OpenFoot Manager.

## Documents

### [GETTING_STARTED.md](GETTING_STARTED.md)

Player-facing gameplay guide covering new games, team selection, dashboard tabs, training, staff, match day, standings, news, and practical tips.

### [ARCHITECTURE.md](ARCHITECTURE.md)

Current web architecture: React, Vite, Vercel API routes, Node server modules, Prisma, PostgreSQL, command flow, frontend state, and deployment shape.

### [WEB_MIGRATION.md](WEB_MIGRATION.md)

Migration notes for the web runtime and the remaining backend parity work.

### [GAME_SYSTEMS.md](GAME_SYSTEMS.md)

Gameplay systems overview: turn processing, training, staff, traits, league generation, inbox, news, world generation, finances, and transfer market behavior.

### [FOOTBALL_STRUCTURE.md](FOOTBALL_STRUCTURE.md)

Target model and roadmap for moving from the current mixed generated league to independent countries, leagues, clubs, cups, continental competitions, and registration rules.

### [DEFINITIONS.md](DEFINITIONS.md)

Schema documentation for external definition files such as `default_names.json` and `default_teams.json`.

## Legacy

The `legacy/` directory keeps older design references that may still be useful while rebuilding deeper simulation systems for the web runtime.
